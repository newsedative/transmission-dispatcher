# Одна ячейка — один робот, кроме фактической передачи

Обычное совместное пребывание двух роботов запрещено. Двое могут находиться
в одной вершине только на границе тактов, когда груз действительно меняет
носителя. Ожидать вместе до или после передачи нельзя. Три робота запрещены
всегда. Исключение определяется по носителю груза и фактическим координатам,
а не по запланированной встрече или тексту журнала.

Это правило действует в общей маршрутизации CBS обоих планировщиков и
независимой потактовой проверке. В пульте передача выделяется голубым,
совместное пребывание без передачи — красным. В метриках записывается
`occupancy_rule=one_robot_except_actual_transfer`.

Простаивающий робот может отойти с ячейки по ограничению CBS. Забрать груз
отказавшего робота можно на единственном фактическом такте передачи:
сломанный робот сохраняет груз до подъёма получателем, затем остаётся один.
Если пустой получатель ломается на встрече до передачи, уже возникшее
совместное пребывание без передачи недопустимо; такой сценарий возвращает
`NO_PLAN`.
